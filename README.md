# CompTIA A+ Study App

An offline study app for the CompTIA A+ exams: **Core 1 (220-1201)** and **Core 2 (220-1202)**.

All the content comes from *The Official CompTIA A+ Core 1 and Core 2 Student Guide*. Every question and every answer explanation gives the page numbers in the guide, so you can look up anything you're unsure about.

> This is an unofficial study tool made by a student. It isn't made or endorsed by CompTIA.

---

## Getting started

1. Download `CompTIA_A+_Quiz.html`.
2. Open it in a web browser (Chrome, Edge, Firefox, or Safari). Double-clicking the file usually works.

That's all. There's nothing to install, and you don't need an internet connection or an account. The app works on a computer and on a phone.

## Quizzes

- Each quiz has 20 questions, picked at random from the module, and the answer order is shuffled every time.
- You can quiz on a whole module or on just one lesson within it.
- **Study mode** shows the answer and explanation right after each question. Leave it off to see your results only at the end.
- Every option has its own explanation, so you learn why the wrong answers are wrong, too.
- **Practise missed questions** builds a quiz from the questions you got wrong.
- The **Ports, Acronyms, and Commands** sections each have a searchable reference list.
- In the **Acronyms** section, Tier 1 covers the acronyms in the official exam objectives and acronym list. Tick **Include Tier 2** to add acronyms that only appear in the chapters.

**Keyboard:** press 1–4 or A–D to choose an answer, Enter for the next question, and the ← → arrow keys to move between questions.

## PBQ practice

These are hands-on tasks like the performance-based questions on the real exam. They include:

- Windows, Linux, and macOS command lines where you type real commands
- A phone you troubleshoot
- A SOHO router admin page, firewall rules, and a Windows IP settings dialog
- A RAID controller and a BIOS/UEFI setup screen
- A laser printer where you name the parts and find the faulty one
- Drag-and-drop cables and connectors, and an RJ45 patch cord to wire
- Event Viewer, NTFS and share permissions, the malware removal steps, and more

Each task gives partial credit and explains every part. Many tasks change each time you try them (different tickets, faults, and settings), so you can't just memorize the answers.

**Tip:** the command lines behave like real ones. If a command asks a question such as `(Y/N)`, type Y or N to answer it.

## Mock exams

The mock exams copy the real exam's format:

- **75–90 items**, a different number each time.
- **4–7 PBQs come first**, then multiple choice. Each PBQ is worth 3 points, with partial credit.
- Questions are picked so each exam domain gets its official share of the points.
- **Timer:** 120 minutes (90 minutes plus 30 minutes of extra time) or 90 minutes (the standard exam time). The exam is submitted automatically when time runs out.
- Flag items for review, and use the review screen to jump back to them.
- Afterwards, you get an **estimated** score on the 100–900 scale (pass mark: 675 for Core 1, 700 for Core 2), a result for each domain, and a full answer review.

The score is only an estimate. CompTIA doesn't publish how raw results convert to the 100–900 scale.

## Your progress

- Your progress is saved automatically in your browser, on your own device. Nothing is sent anywhere.
- Progress stays in the browser you used. A different browser or device starts fresh.
- Clearing your browser's site data erases your progress. You can also reset it on purpose with **Reset all progress**.

## About the content

- Everything is taken from the Student Guide, and only what the guide actually says. If the guide doesn't cover something, it isn't in the app.
- Where the guide contains errors or contradictions, the app avoids testing that point.
- If you find a mistake in the app, please tell the person who gave you the file. Include the question ID (for example `M05-36`) or the PBQ number, so it can be checked against the guide.

Good luck on your exams!
